## 继续复用的数据接口

`src/glaucoma/data.py` 的 `load_records(root, split)` 返回 `Record(image_name, path, age, label)` 列表。

| 字段 | 约定 |
| --- | --- |
| image_name | 保留官方 CSV 的拼写，用于样本和预测身份对齐 |
| path | 磁盘实际路径，已处理文件名大小写；不要直接用 CSV 后缀拼路径 |
| age | 缺失可为 None；原异常值未修正，首轮纯图像基线不必使用 |
| label | 训练/验证为 0 或 1，测试为 None |

该模块不是 PyTorch Dataset，不负责 transform、采样、损失或训练。Dataset 应调用它，不重复实现 CSV 与文件名映射。

## 接入后的实验顺序

| 实验 | 唯一主要变化 | 开始条件 |
| --- | --- | --- |
| B0：复现基线 | 不改 A/C 的现有配置 | 固定数据版本、划分、种子、模型、预算和评估入口 |
| B1：温和增强 | 仅改变训练 transform | 对照增强已记录；验证预处理保持确定性 |
| B2：类别权重 | 仅改变损失权重 | 固定增强和其余训练设置，按相应训练部分统计类别数 |
| B3：阳性过采样 | 仅改变训练采样 | 恢复对照损失，记录每轮样本数、优化步数及成本 |

B2、B3 与同一明确对照比较，不直接叠加。若基线已加权或过采样，先明确单因素对照的定义。单 logit 与双类别 logits 的权重接口不同，不能直接套同一个参数。过采样不改变验证集分布，不额外增加未记录的训练预算。

每组记录 AUROC、AUPRC（注明算法）、固定阈值下召回/精确率、耗时、数据版本、代码/模型版本、种子、样本数及训练步数。短试验用于检查读取、数值与成本，正式对照采用一致预算，有潜力的候选再复跑确认。

质量观察提供亮度和边框方面的线索，不直接决定增强参数。先考虑温和旋转及亮度/颜色扰动，翻转和裁剪强度与 A 一起验证；不默认强裁剪、全量提亮或删除暗图。Focal Loss、欠采样、Age 模型及困难样本挖掘留待核心对照完成后安排。
