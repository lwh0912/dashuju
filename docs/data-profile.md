# 数据画像与少量质量样本复核

2026-10-18 已完成。入口为 `scripts/profile_image_quality.py`，使用本机现有 pandas、NumPy、Pillow、matplotlib，无新增依赖。

## 输入与方法

- 只读 `outputs/image-features/features.csv`、对应的全量完成报告以及三份官方 CSV，按图片名逐一核对集合和标签；不能靠行号直接拼接年龄。
- 分别报告 train/valid/test 的亮度、灰度标准差、暗像素比例、短边和长短边比，包含均值、分位数、尺寸频次、年龄及已知标签分组的统计。
- 尾部参考边界仅用训练集 P01/P99 计算，按严格小于/大于计数，不用于删图或训练过滤。不同指标命中可重叠，数量不能相加。
- 每个划分按 6 个指标方向各选一张，去重时顺延并记录排名，共 18 张；先验证路径、大小和修改时间，再读取这些图片制作原比例缩略图。全部原图不重扫，既有缓存不改。
- 图表使用经验累积分布，各条曲线的分母为各自划分的样本数，避免样本量差异干扰比较。

## 输出

`outputs/data-profile/` 中：

- `report.md`：中文数据画像初稿。
- `report.json`：输入 SHA-256、环境版本、完整统计与待复核样本信息。
- `distributions.png`：分布对比图。
- `review.html`、`contact-sheet.jpg`、`previews/`：18 张质量复核预览。
- `review-notes.md`：本次助手对预览的初步观察和年龄核实清单。由人工单独维护，脚本不覆盖。

预览和逐图数据留在本地。网页仅展示，不自动保存填写；用户可在聊天反馈，另存人工记录，不覆盖原始数据。

## 如何理解

当前三份数据的整体曲线接近，但不能据此排除内容或患者分布差异。灰度统计包含黑边和白色报告背景，不是医学质量评分：含报告版式的图片可能因白背景而具有较高的全图亮度，不能直接判为眼底过曝。年龄异常及缺失的逐图清单留在本地，不默认判无效。近重复和患者重叠尚未排除。

