# 实验认领与记录模板

启动三台机器前先在团队记录中认领，避免重复计算。本模板不代表实验已运行；完整记录放本地 outputs 或赛事允许的存储，Git 只提交不含逐图数据的结论。

| 项目 | 填写内容 |
| --- | --- |
| 实验 ID、负责人、状态 | A/B/C；待运行、运行中、完成或失败 |
| 目的和唯一主要变化 | 对照 ID；不直接叠加采样和大类别权重 |
| 代码与配置 | 仓库、分支、commit、配置校验值；记录未提交改动 |
| 数据与划分 | 数据版本、划分/fold 校验值，不粘贴真实样本清单 |
| 随机种子 | 训练、采样、划分等种子 |
| 模型与输入 | 骨干、初始化、尺寸、预处理和增强 |
| 训练预算 | epoch/步数、每轮样本数、batch size、梯度累积和有效 batch size |
| 设备与环境 | GPU 型号/显存、镜像身份、依赖版本 |
| 指标 | AUROC、AUPRC（AP/曲线积分）、阈值与召回/精确率 |
| 复核与波动 | 另一个种子/折结果，或注明尚未复跑 |
| 成本与产物 | 耗时、显存、权重大小、受控存储位置，不公开逐图预测 |
| 结论 | 保留/放弃/待复核及证据 |
| 赛事提交 | 由 A 统筹；记录配置/模型/阈值与线上分数 |

性能对照另记计时边界、batch=1、预热、CUDA 同步、实际设备。跨卡耗时不直接证明算法优劣，未在 T4 测试时明确注明待验证。
