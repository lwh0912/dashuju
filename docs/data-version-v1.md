# 数据清单 v1：团队交接摘要

整理日期：2026-10-20。版本标识：`official-unchanged-v1-20261020`。本文件只包含方法、汇总结论和使用边界；逐图清单及详细证据保存在本地，不随仓库发布。

## 本版完成了什么

- 已将既有全量读取审计、精确字节查重、全量特征提取、数据画像及用户质量观察整理成版本清单。
- 本地清单覆盖 63,100 条官方样本，与官方 CSV 和特征表的样本身份、标签及划分一致。全部样本保留，未删图、改像素、改标签、填年龄或调整官方划分。
- 官方 CSV 和特征文件 SHA-256 与数据画像的输入快照一致；版本记录包含工具代码基点、输入及产物的 SHA-256。
- 已记录训练集六张质量预览的用户观察，以及年龄缺失和异常的待核实事项。观察与清洗决定分开保存，不自动形成过滤条件。
- 本次仅核对已有表格和报告，没有重复解码、扫描元信息或哈希全部原图。清单中的图片大小/修改时间来自既有特征提取快照，不能据此声称当前原图字节已重新核验。

## 基线如何使用

继续复用 `src/glaucoma/data.py` 读取官方 CSV 和图片，不另建一套文件名映射。数据清单用于版本记录和身份核对，不是新的训练加载器。

首轮建议使用纯图像基线，保留全部样本和原始年龄字段；暂不依赖 Age 的修正结果。允许处理 Age 不等于已经确定缺失/异常值含义或具体替换方案。若后续引入 Age，填补/标准化参数只在相应训练部分拟合，并另立实验和数据变更记录。

训练使用训练划分，开发评估保持独立验证，测试仅作模型预测。最终训练能否合并训练集与验证集，现有答疑存在冲突，需由 A 统筹核实。评分答复也尚未完整明确计算口径；本地继续保存连续概率的 AUROC/AUPRC，以及阈值、预测标签和相应召回/精确率记录。

## 仍未解决的事项

- 精确字节查重没有发现重复组，但近重复与患者重叠尚未排除。dHash 的大量误报、裁剪候选召回盲区和局部验证对翻转的漏检仍存在。
- 质量图册按统计极端程度选样，六张观察不能用于推断全体坏图比例，也不能直接确定统一提亮、裁剪或删除方案。
- 其余质量预览仍可后续复核，不作为团队启动基线的前置条件。
- 本版未完成训练增强、类别不平衡效果对照、训练/预测入口或模型性能验收。
